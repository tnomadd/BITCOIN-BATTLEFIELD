# Bitcoin Battlefield — Greeks vs Mongols

The live Bitcoin market as an ancient 3D battle. Buyers are Greek hoplites (bulls), sellers are Mongol warriors (bears).
Order books, trades and liquidations stream in real time from Binance, Coinbase, Kraken and Bybit.

- Price moves the front line; breaking ±$300 wins the round.
- Trade flow sets the infantry, order-book depth the cavalry, volatility the archers.
- Large buy / sell walls summon **King Leonidas** / **Genghis Khan**.
- Liquidations trigger raids, cavalry charges and rains of fire arrows.

Open `index.html` in Chrome or Edge, or visit the GitHub Pages site. A market visualization, not a price forecast.
